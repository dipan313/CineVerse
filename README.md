## 📖 Overview

**CAREERforge AI** is a complete, futuristic, all-in-one career platform designed to bridge the gap between job seekers and high-compensation engineering roles. 

Instead of fragmented, expensive subscription tools ($20–$50/mo), CAREERforge AI unites everything into a single, cohesive, client-side application with zero vendor lock-in.

---

## ⚡ Core Features

1. **🎯 ATS Resume Analyzer & JD Matcher**
   - 0–100 circular gauge assessing formatting, action verbs, and quantifiable metrics.
   - Semantic keyword radar highlighting matched vs. missing skills against target job descriptions.
   - AI bullet point enhancer transforming weak statements into quantified achievements.

2. **🌐 Portfolio Studio & 1-Click ZIP Exporter**
   - Live interactive split-screen editor with **Desktop (100%)**, **Tablet (768px)**, and **Mobile (375px)** viewport switching.
   - 4 Curated Aesthetic Themes:
     - 🌌 **Cyberpunk Dark**: Glassmorphic dark obsidian, neon cyan/purple accents, and glowing badges.
     - ⚡ **Minimalist Dev**: Clean monospace typography and crisp terminal cards.
     - 🎨 **Creative Editorial**: Bold asymmetrical layout with warm modern styling.
     - 💼 **Executive Platinum**: Refined corporate luxury grid.
   - **Embedded AI Recruiter Chatbot**: Visitors can ask questions about the candidate's experience and receive instant AI answers.
   - **1-Click ZIP Export**: Generates self-contained, zero-dependency `index.html`, `styles.css`, `script.js` ready for free hosting.

3. **🎙️ Real-Time AI Mock Interviewer & Voice Studio**
   - Web Speech API speech-to-text recognition (speak answers) and AI speech synthesis (voice questions).
   - 3 Interview Modes: **Technical Deep-Dive**, **STAR Behavioral**, and **HR & Culture Fit**.
   - Animated 3D soundwave frequency visualizer and post-interview scorecard.

4. **🗺️ Career Roadmap & Skill Gap Visualizer**
   - Identifies skill gaps between current experience and target dream roles (Staff Engineer, AI Systems Architect).
   - Visual milestone roadmap with actionable project guides.

5. **✉️ Recruiter Cold Outreach Studio**
   - High-conversion LinkedIn InMails and tailored cover letters.

## 🚀 1-Minute Free Deployment

### Running Locally
Simply open `index.html` in any modern web browser, or launch a local server:
```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

### Free Cloud Deployment
- **Netlify Drop**: Drag and drop the folder into [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages**: Push to a repository and enable Pages in repository settings.
- **Vercel**: Import repository at [vercel.com](https://vercel.com).
